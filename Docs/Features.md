AI Fitness App – Core Features (3-Month Scope)
1. AI Fitness Chatbot (Main feature of the project)
Functions:
 - Chat with AI about workouts and recovery
 - Get simple fitness recommendations
 - Natural language input
Example: “I did leg day today. How should I recover?”

2. Workout Tracking
Functions:
 - Record exercises, sets, reps, and weights
 - Store workout history
 - Calculate simple Volume-Load
 - 
3. Nutrition AI
Functions:
 - Upload meal photos
 - AI estimates calories and macros
 - Save daily nutrition data

4. Recovery Recommendation System
Functions
 - Suggest hydration and recovery tips
 - Recommend rest or light activity
 - Basic Gym Readiness analysis

5. Activity Tracking
Functions:
 - Read step count from Health Connect/API
 - Track daily activity
 - Combine activity with workout data

6. User Dashboard
Functions:
 - Show workout history
 - Display calories and activity summary
 - Basic charts and progress tracking
